# Homestay

A full-stack premium homestay platform for Uttar Pradesh.

## Project Modules
- **Public Website**: Home, Listings, Details, About, Contact.
- **Property Owner Module**: Dashboard, Property Management, Auth.
- **Admin Panel**: Approval System, Enquiry Management.

## Tech Stack
- Frontend: HTML5, CSS3, JS, Bootstrap 5.
- Backend: PHP (Logic pending).
- Database: MySQL (Schema pending).

## Installation
1. Clone the repository.
2. Deploy to a PHP-enabled server (XAMPP/WAMP/MAMP).
3. Access via browser.
